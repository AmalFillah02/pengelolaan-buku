📚 Sistem Pengelolaan Buku
Sistem Pengelolaan Buku adalah aplikasi berbasis web yang memungkinkan pengguna untuk mencatat, mengelola, dan mencari data buku. Aplikasi ini cocok digunakan di perpustakaan kecil, toko buku, atau kebutuhan pribadi untuk katalogisasi koleksi buku.

🛠️ Fitur Utama
🔐 Login & Register Pengguna

📖 Manajemen Data Buku

- Tambah, edit, dan hapus buku

- Pencarian berdasarkan judul, pengarang, atau kategori

💬 Flash Message untuk notifikasi aksi

🎨 Antarmuka modern dengan SB Admin template & custom CSS
